# atlassian website demo — cloud notes

- Dev: `pnpm dev:atlassian` (port **5183**)
- No env required
- `pnpm test` is Vitest (safe)
- Mock product workspaces: Jira, Confluence, JSM, JPD, Bitbucket, Trello, Loom, Rovo, Admin
- Jira board cards can be dragged between columns; the new status is stored in localStorage
- Unofficial demo — not affiliated with Atlassian Pty Ltd
