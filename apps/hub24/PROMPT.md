# Build HUB24 Demo — hub24.com.au clone, InvestorHUB and AdviserHUB

> Build spec for `apps/hub24`. Generated by the `mock-company-repo` workflow before
> implementation and kept in-tree as the source of truth for what this demo covers.

## Mission

Scaffold a production-quality **HUB24 UI clone** for demo purposes that looks and feels like
[hub24.com.au](https://www.hub24.com.au/). Dummy data only, mock auth, `localStorage`
persistence. No real external services.

**Deliverable:** a single PR against `main` in demo-monorepo with:

1. A complete, lint-clean, build-passing app under `apps/hub24/`
2. A computer-use screen recording of testing the running app, plus key screenshots
3. A PR description covering summary, fidelity, verification, test plan, demo credentials and
   limitations

## Company profile

- **Product:** HUB24 Limited (ASX:HUB) is an ASX 100 financial services company and the operator
  of the HUB24 platform — investment (IDPS), superannuation and pension administration plus
  managed portfolio technology for the Australian wealth industry.
- **Primary users:** financial advisers, private wealth advisers, licensees, investment managers,
  advised clients (investors), and HUB24 shareholders.
- **Core surfaces to clone:** the audience-segmented marketing site (Advisers / Private Wealth /
  Investors / Investment Managers / Licensees), the Platform Features & Benefits section, the
  product catalogue, Insights, CPD education, product documents, About us, the Shareholder
  Centre, and the two authenticated portals — **InvestorHUB** (client) and **AdviserHUB**
  (adviser).
- **Dummy-data theme:** Australian wealth management — managed portfolios, ASX-listed
  securities, managed funds, term deposits, super and pension accounts, adviser client books.

## Repo context

- Repo: `demo-monorepo` (pnpm workspace, `apps/*` + `packages/ui`)
- App directory: `apps/hub24/`, package name `hub24-website-demo`, dev port **5181**

## Target tech stack

| Layer      | Technology                                            |
| ---------- | ----------------------------------------------------- |
| Framework  | Vite 6 + React 19 + TypeScript (strict)               |
| Styling    | Tailwind CSS v4, CSS-first `@theme` tokens            |
| Components | Hand-rolled primitives in `src/components/ui`         |
| Icons      | lucide-react                                          |
| Forms      | react-hook-form + zod                                 |
| Routing    | react-router-dom v7 (`BrowserRouter`)                 |
| State      | React context + hooks                                 |
| Data       | Typed TS seed modules under `src/data`                |
| Auth       | Mock base64 session in `localStorage`                 |
| Tests      | Vitest + React Testing Library                        |
| Lint       | ESLint 9 flat config + Prettier (root config)         |

Explicitly do **not** integrate real databases, cloud providers, CMS APIs, OAuth or payments.

## Design system

Deep navy surfaces with a teal accent, generous white space, rounded cards, geometric
display type. Tokens live in `src/index.css` under `@theme` with a `--color-h24-*` prefix.
Never share Tailwind config with another app.

Primitives to build: `Button`, `Card`, `Badge`, `Field`, `Tabs`, `Accordion`, `DataTable`,
`Stat`, `SectionHeading`, `ProgressBar`, `Toggle`, `Avatar`, `EmptyState`, `LoadingSkeleton`.

## Data layer

Realistic Australian wealth-management dummy data with 25+ rows wherever a table paginates or
filters. Portfolio mutations (trades, cash movements) persist to `localStorage`.

## Auth (mock)

Protect portal routes; unauthenticated visits redirect to `/login?redirect=…`. Session is a
base64 JSON blob under `hub24-demo-session`. Logout clears it.

## Tests (minimum)

Formatters, session encode/decode, seed-data integrity, portfolio maths, key components,
marketing page rendering, and both portals including a trade that changes holdings.

## Computer-use verification (required before PR)

Start the app, then walk: marketing landing → login with demo credentials → InvestorHUB
portfolio dashboard → place a trade in AdviserHUB. Record the walkthrough to video and capture
stills for the PR.
