# Employment Hero app guidance

- This is an unofficial Vite + React 19 demo running on port 5180.
- Keep every visual value in `src/index.css`; use the app’s Employment Hero tokens rather than inline hex values.
- Use `cn` from `src/lib/cn.ts`, `lucide-react` icons, and semantic accessible controls.
- Keep all people, payroll, hiring, resource, and form data local and fictional.
- `/login` is deliberately broken through a case mismatch in portal configuration. Do not fix it unless the related bug-fixing demo is explicitly requested.
- Run `pnpm test`, `pnpm lint`, `pnpm typecheck`, and `pnpm build` in this app after changes.
